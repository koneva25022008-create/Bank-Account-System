# Bank Account System

## Автор
**Конева Диана** 

## Краткое описание
Консольное приложение "Bank Account System" для управления банковскими счетами. Поддерживает различные типы счетов (расчетный, сберегательный, кредитный), выполнение транзакций (пополнение, снятие, перевод), историю транзакций с фильтрацией, сохранение и загрузку данных в JSON.

### Возможности
- ✅ Создание счетов разных типов
- ✅ Пополнение и снятие средств
- ✅ Перевод между счетами
- ✅ История транзакций с очередью
- ✅ Фильтрация по дате и типу
- ✅ Сохранение/загрузка в JSON
- ✅ Обработка ошибок
- ✅ MVC архитектура
